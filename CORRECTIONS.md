# Corrections log

We fix mistakes in public. If a post, chart or data file has a mistake, we change it, add a note at the top of the post, and add an entry here. We do not edit things quietly.

Each entry has:

- an ID (C-001, C-002 and so on)
- the date we found the mistake and the date we fixed it
- the post number and its link
- what was wrong (the old text or number)
- what is right (the new text or number)
- the cause
- who found it and who checked the fix
- any chart or CSV files that changed

Newest entries go first.

How to report a mistake: email hello@starfield.net.
